# Ticket #1049: PNR-404 booking not found

**Channel:** web chat

**Customer message:**
> Trying to pick seats. It says PNR-404 booking not found. Code is K0PL9X, name Fernandes-Rao. booked thru a travel website 20 min ago

**Agent resolution:**
Pointed out that SkyDesk references never contain the digit 0, so the second character was likely the letter Q or D, and that double-barrelled names are entered without the hyphen (FERNANDESRAO). Also explained that bookings from travel websites can take up to 2 hours to appear. The customer retried an hour later with KQPL9X and FERNANDESRAO and found the booking.

**Resolution code:** RES-INFO
