How the SkyDesk Assistant works

A LangGraph agent that verifies you, looks up your booking, checks policy as code, quotes exact amounts, and proposes changes that pause for a supervisor's approval.

Read toolsVerify identity, look up bookings, check eligibility, quote amounts, search the help center. These run on their own, with timeouts and retries.
Write toolsRebook, refund, voucher, waive fee, update contact, cancel. Each one pauses for supervisor approval and runs only with that approval id.
NumbersEvery amount in a reply must match a quote from our systems. If a price can't be verified, it is withheld or the case goes to a person.
Hand-offBereavement, legal, fraud and chargebacks always go to a person, as does any case the assistant can't finish safely.
MemoryEach chat is a thread saved in a SQLite checkpointer, so a pending approval survives a restart.
